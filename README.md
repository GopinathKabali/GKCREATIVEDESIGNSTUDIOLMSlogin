# GK Creative Design Studio LMS

A responsive, dependency-free design learning portal.

## Features
- Four courses and fifteen guided lessons with practical exercises
- Course search and category filters
- Lesson completion and browser-local progress
- Course completion achievements
- Three downloadable practice resources
- Responsive layouts and keyboard-accessible controls

## Run
Serve this folder using any static HTTP server, or open index.html.

## Deploy with Vercel
Import this repository into Vercel. Choose Other as the framework preset, leave the build command empty, and serve the repository root. No environment variables or install step are required.

## Scope
This first version uses browser localStorage. It does not include authentication, shared student records, video hosting, instructor administration, or payment processing. Clearing browser storage removes learning progress. Course completion records are local achievements, not accredited certificates.
